# Contributing

1. Open an issue describing the problem or proposed improvement.
2. Keep changes focused and avoid unnecessary dependencies.
3. Add or update tests for behavioral changes.
4. Run `python -m pytest` and `python -m ruff check .`.
5. Document security implications and any new data collection.
6. Submit a pull request with a concise rationale.

Only contribute defensive, authorized research functionality. Do not add covert instruction payloads, unauthorized agent-control behavior, or code that executes untrusted observations.
